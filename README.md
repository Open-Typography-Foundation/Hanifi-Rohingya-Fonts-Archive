Right-to-left indigenous alphabet developed in the 1980s by Maulana Mohammad Hanif for the Rohingya language, officially encoded in Unicode 11.0.

---

## 🌟 Typographic Specimen

```text
𐴎𐴟𐴔𐴧𐴝 𐴔𐴝𐴥𐴎𐴟𐴡 𐴀𐴝𐴎𐴝𐴊𐴞 𐴇𐴞𐴏𐴝𐴠𐴁𐴠 𐴀𐴝𐴌 𐴐𐴝𐴚 𐴀𐴞𐴎𐴧𐴡𐴃𐴠
```

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Hanifi-Rohingya-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Hanifi-Rohingya-Fonts-Archive/main/install.ps1 | iex
```
